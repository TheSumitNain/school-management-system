
# School Management System

A multi-tenant School Management System designed for commercial use.

## Technology Stack

- Frontend: React + TypeScript
- Backend: Go + Gin
- Database: PostgreSQL

## Initial Target

- 25–30 schools
- Approximately 400–500 students per school

## Project Principles

- Security and school-level data isolation are enforced by the backend.
- Automated testing is required for implemented features.
- Database schema changes are managed through versioned migrations.
- Secrets and credentials must never be committed to Git.
- API behavior and architecture must be documented.
- Features are implemented incrementally and verified before moving forward.

## Project Status

Initial setup. No application features have been implemented yet.
